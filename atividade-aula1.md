Caderno de respostas da aula 01

1. Objetivo
A aula teve como objetivo aprender os conceitos básicos de virtualização e instalar o sistema operacional Ubuntu Server 26.04 utilizando o VirtualBox.

2. Procedimentos realizados
Inicialmente, foram organizadas as pastas para armazenar os arquivos da máquina virtual. Em seguida, foi criado um ambiente virtual no VirtualBox com 768 MB de memória RAM, um processador e um disco virtual de 32 GB. Depois, foi selecionada a imagem ISO do Ubuntu Server 26.04 e iniciada a instalação do sistema. Durante o processo, foram configurados o idioma, o teclado, a rede e o particionamento do disco, incluindo as áreas /boot, / e SWAP.

3. Conclusão
A atividade permitiu compreender as etapas básicas de criação de uma máquina virtual e instalação de um sistema operacional servidor.
